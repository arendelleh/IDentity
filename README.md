# IDentity

A student profile Android app built with **Kotlin** and **XML layouts** in Android Studio.

## Features
- Scrollable profile with an initials avatar and academic details.
- Pink theme, readable typography, and system-bar spacing.
- Student number omitted from the public portfolio version.

## Run
Open this folder in Android Studio, sync Gradle, select an Android phone or emulator (Android 7.0 / API 24 or later), and run the app module.

## Stack
Kotlin, Android Views, XML resources, AndroidX AppCompat, Gradle Kotlin DSL.
